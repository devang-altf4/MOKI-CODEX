# Current local typeface

League Spartan is used for headings, reading text, navigation and controls. The family and weights were identified from WeAreBrand's actual computed heading, paragraph and button styles on 2026-11-04. The reference uses weight 500 for its main headings and paragraphs and 600 for its request button.

The variable Latin font (weights 400–700) was obtained independently from official Google Fonts, rather than copying the reference site's font files:

- `league-spartan.woff2`: local delivery font.
- `league-spartan-source.css`: official Google Fonts CSS response.
- `LEAGUE-SPARTAN-LICENSE.txt`: SIL Open Font License, from `google/fonts/ofl/leaguespartan/OFL.txt`.

No Google Fonts requests are made at runtime. Manrope remains available solely to preserve the existing MOKI wordmark. Earlier font files are retained as assets of previous local revisions and are not preloaded by the current page.
